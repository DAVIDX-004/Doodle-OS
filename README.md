# Doodle OS

![Doodle OS Screenshot](screenshot.png)

Doodle OS is a web-based operating system. This operating system was created in boredom, when I asked myself what an alternative version of a computer operating system looks like. There is a login window, draggable windows with controls, a notepad that actually stores files in local storage, terminal with some commands, calculator, file manager, snake game that is controlled with the use of arrow keys, browser launcher, and settings window to switch between light and dark modes. This project is implemented completely on HTML, CSS, and JavaScript without any framework or build step. Just open index.html.

Initially, it all began from a welcome screen page, and then I started adding new features just because it was fun to make something with JavaScript without frameworks. Window manager turned out to be a hard nut to crack, making windows draggable, determining active window, and implementing window close feature. Another funny moment of this development was debugging reasons for not working login button, when the problem was found to be caused by declaration of a variable that does not yet exist in DOM. Colors come from pastel highlighters of school years, and thick borders and shadows were chosen to create a handmade feel of the application.
You can try the live version at https://DAVIDX-004.github.io/Doodle-OS -- the password is "doodle" if you want to see past the login screen.
