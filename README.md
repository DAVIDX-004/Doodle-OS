# Doodle OS

![Doodle OS Screenshot](screenshot.png)


This is a simple desktop simulation I made in my browser. I built it because I wanted to see if I could make something that looks like a real computer OS. It is not a real OS, just a website that acts like one.

I learned HTML, CSS, and JavaScript from W3Schools and YouTube videos. I followed them and kept adding my own stuff to it.

## What it has

- Login screen with password "doodle"
- Desktop with app icons
- Windows you can drag around, close, minimize, and maximize
- Notepad that saves files to your browser's local storage
- Terminal with some basic commands
- Calculator
- File manager to see and delete saved files
- Snake game you play with arrow keys
- Browser that opens websites in a new tab
- Settings to switch between light and dark mode

## How to run it

You do not need to install anything. Just open `index.html` in your browser. It works without any frameworks or build steps.

You can also try it here: https://DAVIDX-004.github.io/Doodle-OS

The password is **doodle** if you want to get past the login screen.

## What I used

- HTML
- CSS
- JavaScript
- Font Awesome for the icons

That is it. No React, no Vue, no build tools.
